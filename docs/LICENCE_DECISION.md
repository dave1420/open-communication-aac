# Open-Source Licence Decision

David selected **Mozilla Public License 2.0 (MPL-2.0)** on 30 September 2026 for the public repository. See the root `LICENSE` file for the full terms.

The app is free to use and share. MPL-2.0 requires distributed changes to covered files to remain available under the same licence, supporting continued access to improvements.

## Practical choices

- **Apache-2.0:** permissive reuse with an explicit patent grant and notice requirements. Good for broad adoption, including commercial integrations.
- **MPL-2.0:** file-level copyleft. Modified covered files remain open, while the code can be combined with differently licensed software.
- **GPL-3.0:** strong copyleft for distributed applications. Derivative distributed works must provide corresponding source under the GPL.
- **AGPL-3.0:** GPL-style copyleft that also addresses modified versions offered as a network service.

The licence for code is separate from licences for pictograms, photographs, recorded voices, sample boards, and documentation. Every asset source and attribution requirement must be recorded. Do not add patient information or private family media to the public repository.

This note is a project decision aid, not legal advice.
